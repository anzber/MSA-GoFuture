# Task 4. Платформа данных для ML и BI "GoFuture"

Родительские артефакты: [`../Task1/`](../Task1/) (сервисы и данные), [`../Task2/`](../Task2/)
(событийная платформа), [`../Task3/`](../Task3/) (регионы).

## 1. Контекст

"GoFuture" нужна единая платформа для сбора, обработки и анализа данных для ML-моделей
динамического ценообразования, прогнозирования спроса и обнаружения мошенничества. Данные
приходят из всех микросервисов; их нужно собрать, обработать и отдать в ML-платформу и
BI-инструменты.

## 3. Решение на одном экране

1. **Сбор** - все доменные события и изменения данных попадают в шину событий (Kafka) через
   транзакционный outbox и CDC (см. Task2). Это единый источник данных, без ручных выгрузок.
2. **Обработка** - потоковая (Flink) для реального времени и пакетная (Spark + Airflow) для
   витрин и признаков; оркестрация пакетных задач - Airflow.
3. **Хранение** - озеро данных (объектное хранилище) для "сырых" и больших данных,
   хранилище аналитики (ClickHouse) для быстрых витрин.
4. **ML-платформа** - витрина признаков, обучение моделей, реестр моделей и онлайн-инференс;
   результаты моделей возвращаются в доменные сервисы.
5. **BI** - DataLens поверх витрин ClickHouse.
6. **Качество данных** - проверки на каждом шаге, изоляция "плохих" записей, контроль
   происхождения данных и мониторинг (см. ADR-002).

## 4. Ключевые компромиссы

| Решение | Почему | Компромисс/риск |
|---|---|---|
| Сбор через события, а не прямыми запросами к БД сервисов | нет связанности, единый поток | итоговая согласованность, задержка |
| Разделение потоковой (Flink) и пакетной (Spark) обработки | каждая задача - своим инструментом | два стека в эксплуатации |
| Озеро данных + аналитическое хранилище | дешёвое сырое хранение + быстрые витрины | дублирование данных, нужно управлять |
| Витрина признаков для ML | повторное использование признаков, единый расчёт | дополнительный компонент и его эксплуатация |
| Проверки качества в конвейере | данные для ML должны быть достоверными | задержка обработки, стоимость проверок |
